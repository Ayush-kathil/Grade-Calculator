# Academic Performance Analytics & Planning Dashboard

An ultra-modern, dynamic academic tracker and predictive analytics engine. Designed for exceptional readability, precise computational accuracy, and modern aesthetics.

## Features

- **Four Analytical Processing Engines:** 
  - **Percentage Tracking:** Rapid exact scoring percentage calculation.
  - **SGPA Modeler:** Compute Semester Grade Point Average with precise module grade point matrices.
  - **CGPA Modeler:** Advanced semester cumulative projection combining past analytics with upcoming workloads.
  - **What-If Scenarios Modeler:** Target modeling to project what average marks are required to hit specific future goals.
- **Dynamic Dual Theme Engine:** Toggle effortlessly between clean light mode and immersive dark mode.
- **Session History:** Seamless persistence of recent calculations using direct browser caching mechanisms.
- **Professional Engineering:** Clean, production-ready source code written in TypeScript and Next.js.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the dashboard.

## Technical Details

Built using **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**. All analytical processes and projections run entirely on the client side without needing database backend storage.
